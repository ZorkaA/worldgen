# Procedural World Manifest Importer for Unity

The **World Manifest Importer** is a C# Unity Editor package that automatically instantiates procedural battle-royale and military environments from a `world_manifest.json` file generated by the FastAPI WorldGen backend.

---

## Key Features

1. **Unity Terrain Instantiation (`TerrainGenerator`)**:
   - Creates or updates Unity `Terrain` GameObject with `TerrainData` and `TerrainCollider`.
   - Bilinear heightmap interpolation from arbitrary manifest resolutions (e.g. 256, 500, 512) to valid Unity heightmap resolutions ($2^n + 1$, e.g. 65, 129, 257, 513, 1025).
   - Strict height normalization to $[0.0, 1.0]$ matching Unity's coordinate ordering (`float[z, x]`).
   - Sets exact terrain bounds: `terrainData.size = new Vector3(width, height_scale, length)`.

2. **Prefab Spawning with Live Link Preservation (`PrefabSpawner`)**:
   - Uses `PrefabUtility.InstantiatePrefab(prefabAsset, parentTransform)` in Editor mode to preserve authentic links to project prefab assets.
   - Automatically searches and indexes prefabs in `Assets/PolygonMilitary/Prefabs/` (and recursively across project folders).
   - Fallback to bounding-box-proportional proxy cube if an asset is missing in the project, with descriptive warning logging.
   - Accurately applies Position, Rotation (Euler or Quaternion), and LocalScale.

3. **Faction & Destruction Material / Texture Swapping (`MaterialSwapper`)**:
   - Identifies Zone Faction (`A`, `B`, `C`) and Destruction state (`01`, `02`, `03`, `04`).
   - Replaces swappable materials with pre-compiled Synty material assets: `PolygonMilitary_Mat_{destruction}_{faction}.mat`.
   - Dynamic fallback: overrides `_MainTex` with `PolygonMilitary_Texture_{destruction}_{faction}.png` and `_BumpMap` with `PolygonMilitary_Texture_01_A_Normals.png`.
   - **Selective Preservation**: Preserves special materials intact (`PolygonMilitary_Glass_01`, `PolygonMilitary_Vehicles`, `Decals`, `FX`).

4. **3D Road Ribbon Mesh & Splines (`RoadMeshBuilder`)**:
   - Generates smooth Catmull-Rom centripetal splines through road waypoints.
   - Conforms road elevation to the procedural terrain with $+0.15\text{m}$ clearance to eliminate z-fighting.
   - Builds 3D Quad Ribbon Mesh with normals, tangents, and UV coordinates.
   - Optionally attaches companion `LineRenderer` components.

5. **Clean Scene Hierarchy & Undo Integration**:
   - Hierarchical scene organization:
     ```
     [WorldGen_Output]
     ├── Terrain (Terrain + TerrainCollider)
     ├── Roads
     │   ├── Road_road_0_1 (MeshFilter + MeshRenderer + LineRenderer)
     │   └── Road_road_1_2
     └── Zones
         ├── Zone_zone_0_FactionA_Destruction02
         │   ├── SM_Bld_Tent_01_bld_0
         │   └── SM_Bld_Watchtower_01_bld_1
         └── Zone_zone_1_FactionB_Destruction01
             └── SM_Bld_Hangar_01_bld_2
     ```
   - Complete `Undo` support via `Undo.RegisterCreatedObjectUndo` and `Undo.DestroyObjectImmediate`.

## How to Use

1. Open your Unity Project (Unity 2020.3 LTS or newer).
2. Copy `unity/Assets/Editor/WorldManifestImporter.cs` into your project's `Assets/Editor/` folder.
3. In Unity Editor menu bar, click:
   `WorldGen -> Import World Manifest`
4. In the Importer window:
   - Click **Browse...** to select your `world_manifest.json` file.
   - Verify or customize the search folders for Prefabs, Materials, and Textures.
   - Configure options (Terrain, Buildings, Materials, Roads).
   - Click **IMPORT WORLD MANIFEST**.
5. To clear generated worlds, click `Clear Generated World` in the window or via `WorldGen -> Clear Generated World`.
