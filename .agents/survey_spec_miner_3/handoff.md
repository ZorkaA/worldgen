## 2. Logic Chain
1. *From Observation 1 & 2*: The Synty PolygonMilitary asset pack follows a deterministic naming convention for 4 damage tiers (`01`, `02`, `03`, `04`) and 3 factions (`A`, `B`, `C`). Therefore, both the Three.js frontend and the Unity Importer can deterministically look up materials and textures using the template string `PolygonMilitary_Mat_{destruction}_{faction}` and `PolygonMilitary_Texture_{destruction}_{faction}`.
2. *From Observation 1 & 4*: For the Vite + Three.js frontend, rendering heightmap terrain requires a `PlaneGeometry` with vertex coordinates updated along the Y-axis from the backend's elevation grid. Placing building bounding boxes requires lightweight wireframe box geometry and instanced rendering, while road networks require `CatmullRomCurve3` spline ribbons with quad vertices aligned to terrain height. The UI side panels must use container queries, stable scrollbar gutters, and responsive layouts to satisfy `modern-web-guidance`.
3. *From Observation 1 & 2*: In Unity Editor, spawning prefabs must use `PrefabUtility.InstantiatePrefab` rather than `Object.Instantiate` to preserve prefab asset linkages and prevent breaking prefab variants. The terrain heightmap array must be normalized to $[0.0, 1.0]$ and assigned via `TerrainData.SetHeights(0, 0, heights2D)` with $2^n + 1$ resolution matching.
4. *From Observation 1 & 3*: Verification requires two automated pytest suites (`test_manifest_schema.py` and `test_generator.py`) and a standalone CLI validator (`validate_catalog.py`). Automated Agent-as-Judge review rubrics ensure strict adherence to Vite build cleanliness, Three.js scene architecture, Unity C# syntax, and material swap integrity.

## 3. Caveats
- Unity Editor execution occurs within the user's Unity environment; C# scripts must be written without external non-standard DLL dependencies so they compile immediately in standard Unity 2021/2022/2023/6 LTS projects.
- Heightmaps generated by the backend with dimensions $N \times N$ (where $N = 2^k$, e.g., 512) require bilinear interpolation to $(N + 1) \times (N + 1)$ (e.g. 513) when constructing Unity's `TerrainData`.
