# Master Plan — Procedural Military World Designer & Unity Importer

## Overview
Implement a full-stack procedural 3D military world generation system with:
1. Asset Catalog Builder (Blender CLI bbox extraction, multi-angle render, Ollama VLM tagging, cached `catalog.json`).
2. FastAPI Backend (Perlin multifractal, domain warp, Numba hydraulic erosion, Poisson-disc zones, bbox-aware building placement, slope-aware A* roads, `world_manifest.json` export).
3. Interactive 3D Frontend (Vite + Three.js, visualizer, config side panels, asset catalog browser).
4. Unity C# Importer (Unity Terrain heightmap instantiation, prefab spawning via `PrefabUtility.InstantiatePrefab`, material swapping for factions A/B/C and destruction 01-04).
5. Comprehensive Test Suite & Acceptance Criteria verification (schema validation, agent rubrics, E2E tests).

## Milestones
- **Survey Phase**: 3 parallel Explorers to survey available tools (Blender, Ollama, Python/uv, Node, Synty assets / models / textures / prefabs), analyze environment constraints, and specify contracts.
- **E2E Testing Track**: Build standalone test harness, schema validators, mock/golden generators, integration verification scripts.
- **Milestone 1 (R1)**: Asset Catalog Builder & Blender/VLM Pipeline.
- **Milestone 2 (R2)**: Procedural Terrain & Zone Generator Backend.
- **Milestone 3 (R3)**: Interactive 3D Frontend (Vite + Three.js).
- **Milestone 4 (R4)**: Unity C# Importer Package.
- **Milestone 5 (Verification & Integration)**: Full E2E verification, test execution, rubric evaluation, final forensic audit.
